# AI ATLAS — 1,000+ AI TOOLS EXPANSION PRD

## 1. OBJECTIVE

Expand AI Atlas into a structured, high-quality AI tool discovery platform containing an initial target of **1,000 real AI tools** across major categories.

Do not simply add 1,000 cards.

The goal is to create a system where every tool is:

* Structured
* Categorized
* Searchable
* Filterable
* Verifiable
* Comparable
* Recommendation-ready
* Connected to capabilities and use cases
* Useful for AI Stack generation

The final experience should help users answer:

> **“What AI tool should I use for my specific goal?”**

rather than:

> **“Here are 1,000 AI tools. Good luck.”**

---

# 2. MOST IMPORTANT PRODUCT RULE

**Quality > quantity.**

Do not create fake tools, fabricated information, copied fictional pricing, fake reviews, fake ratings, or invented statistics to reach 1,000.

The target is:

**1,000 real tools**

not:

**1,000 database records pretending to be real tools.**

Every published tool must have enough verified information to be useful.

# 9. TOP 100 SYSTEM

Build a dynamic **Top 100** page.

Do not manually enter rankings.

Create a ranking pipeline based on legitimate signals such as:

* Recommendation relevance
* Verified quality
* Reliability
* User engagement
* Save rate
* Outbound interest
* Review quality where sufficient
* Recency
* Data confidence

Do not allow raw traffic alone to determine the ranking.

Avoid creating a popularity loop where already-popular tools automatically become more popular.

Use ranking diversification.

# 10. TRENDING SYSTEM

Trending should be based on actual recent activity.

Potential signals:

* Recent searches
* Recent tool views
* Recommendation clicks
* Saves
* Outbound clicks
* Growth compared with previous period
* Recently added tools

Calculate a normalized trending score.

Example conceptual model:

```text
Trending =
recentGrowth
+ engagementGrowth
+ searchGrowth
+ recommendationGrowth
```

Use time windows such as:

* 24 hours
* 7 days
* 30 days

Do not fabricate trending data.
