## 🌟 Overview

**AI Atlas** is an intelligent decision engine and goal planning suite that helps developers, founders, creators, and researchers find, compare, and connect the right AI tools for any objective.

Rather than acting as a passive, unverified directory with inflated metrics, AI Atlas focuses on **decision quality and working execution modules**:
1. **Goal & Stack Planner (`/plan`)**: Users describe what they want to accomplish. AI Atlas deconstructs the objective into sequential phases, pairs verified tools with budget alternatives, audits budget limits, detects capability redundancies, and outputs an actionable Markdown blueprint.
2. **Subscription Redundancy & Cost Optimizer**: Analyzes stacks to detect overlapping subscriptions (e.g. paying for multiple text generation models) and calculates exact potential monthly savings.
3. **Deep Comparative Trade-Off Analyzer (`/compare`)**: Evaluates up to 4 tools side-by-side with verified latency, pricing models, limitations, and platform support.
4. **91 Fact-Verified Flagships + Connected Open Model Registry**: Grounded in manually audited data with zero hallucinated prices, complemented by live search across open-weights models and pipelines.

## ⚡ Core Modules & Features

### 1. 🤖 Autonomous Goal Planner & Analyzer (`/plan`)
- **Phase Deconstruction**: Breaks down high-level project goals into step-by-step technical phases (e.g., Ideation → Scripting → Voiceover → Visuals → Video Assembly).
- **Tool Pairing with 1-Click Swap**: Assigns the #1 ranked primary flagship tool alongside a budget-friendly or open-source alternative. Users can swap tools in one click with live cost recalculation.
- **Budget Guardrails**: Enforces monthly budget caps and flags financial surplus or overshoots.
- **Exportable Blueprints**: Generates copyable Markdown project specifications and allows 1-click saving directly to custom user stacks.

### 2. 💸 Capability Redundancy & Cost Auditor (`/stacks`)
- Identifies duplicate capability coverage across selected tools.
- Highlights overlapping subscription costs (e.g. ChatGPT Plus + Claude Pro + Jasper).
- Recommends consolidation onto the most cost-effective solution, showing exact potential monthly savings.

## 🏗️ Architecture & Tech Stack

- **Framework**: Next.js 16.3.4 (App Router, Turbopack, React 19)

- **Styling**: Tailwind CSS v4 with bespoke holographic glassmorphism and ambient lighting
- **Database Layer**: Dual-mode repository with Firebase Firestore sync + fast in-memory fallback
- **Authentication**: Firebase Authentication with role-based access control (Admin / User)
- **Testing**: Vitest test suite (`npm run test`)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Channu0012/AI-Atlas.git
cd AI-Atlas
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Run automated tests
```bash
npm run test
```

### 5. Build for production
```bash
npm run build
```
