## 🌟 Overview

**AI Atlas** is an intelligent decision engine and workflow synthesizer that helps developers, founders, creators, and enterprises find, compare, and connect the right AI tools for any objective.

Rather than scrolling through endless generic directories, users specify what they want to accomplish. AI Atlas executes a deterministic weighted-sum recommendation algorithm to retrieve verified tools, explains the architectural trade-offs, calculates true monthly stack costs, connects them into end-to-end production workflows, and queries over **100,000+ open-source AI models and tools** backed by Firebase Firestore.

## ⚡ Core Features

- **🎯 Goal-Driven Intent Extraction**: Parses user goals into required capabilities, domain contexts, target skill levels, and platform constraints.
- **🌌 100,000+ AI Universe Explorer**: Live search integration across 400,000+ open-weights models and pipelines from the Hugging Face and Open Source registry, auto-cached to Firebase Firestore.
- **🛡️ 91 Fact-Verified Flagship Tools**: Comprehensive, manually verified data profiles with transparent pricing models (free, freemium, paid, custom), exact platform support, honest strengths, and clear limitations. Strictly zero hallucinations.
- **🌐 16 Global AI Taxonomy Sectors**:
  - AI Coding & Development (Cursor, Replit Agent, Aider, Tabnine, Continue, Cody, Supermaven)
  - Multimodal LLMs & Frontier Reasoning (ChatGPT, Claude, Gemini, Grok, DeepSeek)
  - AI Video & Motion (Runway Gen-3, Luma Dream Machine, Hailuo AI, Kling, InVideo, Topaz Video AI, OpusClip, Kaiber)
  - AI Voice, Audio & Music (ElevenLabs, Suno, Udio, PlayHT, Soundraw, Murf, Krisp, Otter.ai, Riffusion)
  - AI Design, Images & 3D (Midjourney, FLUX.1, Ideogram 2.0, Leonardo.Ai, Adobe Firefly, Spline AI, Meshy, Tripo3D, Magnific AI, Recraft)
  - AI Research, Citations & Science (Perplexity, Elicit, Consensus, scite.ai, Connected Papers, Scholarcy, NotebookLM)
  - Autonomous Agents & Computer Use (Claude Computer Use, Manus AI, AutoGen, CrewAI, Browser-Use)
  - Local, Privacy & Edge AI (Ollama, LM Studio, Jan.ai, ComfyUI, LocalAI, vLLM)
  - AI Automation & Workflows (Make.com, n8n)
  - AI Productivity & Office (Notion AI, Gamma, Tome, Beautiful.ai, Fireflies.ai)
  - AI Marketing, Copywriting & SEO (Jasper, Copy.ai, Writesonic, Surfer SEO, Clay)
  - Data Science & SQL AI (Julius AI, Vanna.ai, Hex)
  - Customer Support & Service AI (Intercom Fin)
  - Education & Tutoring (Khanmigo, Duolingo Max)
  - Finance, Legal & Compliance AI (Harvey AI)
  - Media Enhancement & Upscaling (Topaz, Magnific, Krisp)
- **⚖️ Side-by-Side Comparison Matrix**: Compare up to 4 AI tools simultaneously across pricing, platforms, strengths, limitations, and API availability.
- **🏗️ AI Stack Builder & Cost Calculator**: Interactive workbench to combine AI tools into production pipelines with instant monthly expenditure calculations.
- **🔄 Multi-Step Production Workflows**: Curated step-by-step blueprints (e.g., YouTube video creation, rapid MVP web apps, private offline LLM pipelines, academic literature reviews).
- **🔒 Admin Governance Console**: Audit logging, verification timestamp updates, tool review queues, and user role management.

## 🏗️ Architecture & Tech Stack

- **Framework**: Next.js 16.3.4 (App Router, Turbopack, React 19)
- **Language**: TypeScript 5 (strict type-checking)
- **Styling**: Tailwind CSS v4 with custom holographic glassmorphism and ambient lighting
- **Backend / Database**: Isomorphic repository layer with Firebase Firestore + in-memory fallback
- **Authentication**: Firebase Authentication with development role-switching support
- **Testing**: Vitest unit test suite

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Channu0012/AI-Atlas.git
cd AI-Atlas
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

### 4. Run tests
```bash
npm run test
```

### 5. Build for production
```bash
npm run build
```
